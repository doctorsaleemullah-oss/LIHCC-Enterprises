Connect to Supabase Cloud

One-time setup — 5 minutes. Free forever.

STEP 1

Go to supabase.com → Sign up free → Create a new project (any name, e.g. "medcathkhata")

STEP 2

In your project → go to SQL Editor → paste and run this SQL to create your tables:

create table parties ( id text primary key, name text, type text, phone text, openingBalance numeric, notes text ); create table products ( id text primary key, name text, unit text, defaultPrice numeric, defaultCost numeric, stock numeric ); create table transactions ( id text primary key, partyId text, type text, date text, items jsonb, total numeric, paid numeric, balance numeric, notes text, isPayment boolean ); create table app_settings ( id integer primary key, data text );
STEP 3

Go to Settings → API in your Supabase project. Copy your Project URL and anon/public key and paste below:

STEP 4

In Supabase → Authentication → Policies, for each table run:
ALTER TABLE parties ENABLE ROW LEVEL SECURITY;
Then add a policy: Allow all for anon (since this is your private app).

Or in SQL Editor run this shortcut:

create policy "allow all" on parties for all using (true); create policy "allow all" on products for all using (true); create policy "allow all" on transactions for all using (true); create policy "allow all" on app_settings for all using (true);
